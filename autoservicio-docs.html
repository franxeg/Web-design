Manual de uso

Instalación Descargar instalador

1. Instalación

Requisitos

Windows 10 o 11, 4 GB de RAM y aproximadamente 200 MB libres. No necesitás Docker ni instalar PostgreSQL: el instalador ya incluye todo.

Paso 1 · Descargar

Bajá Autoservicio-1.0.1-Setup.exe desde el release público de GitHub y ejecutalo.

Descargar

Paso 2 · SmartScreen

El instalador no está firmado digitalmente. Si Windows muestra una advertencia, elegí Más información y después Ejecutar de todos modos.

Paso 3 · Instalar

Seguí el asistente con las opciones por defecto. La primera vez tarda 1 o 2 minutos porque prepara la base de datos. Al terminar se abre el navegador en http://localhost:3000.

2. Primer registro

Crear la cuenta

Entrá a http://localhost:3000/registro (necesitás conexión a internet) y completá nombre del negocio, usuario y contraseña. La cuenta arranca con 30 días de prueba.

Usuario administrador

Después del registro, el sistema te pide completar la configuración inicial con tu usuario administrador definitivo. Ese usuario es el que usarán los empleados con rol ADMIN.

Ingresar después

En próximos arranques abrí http://localhost:3000/login e iniciá sesión con tu usuario y contraseña. Si el sistema ya está registrado, la opción de registro no vuelve a aparecer.

¿Por qué pide internet?

Solo para registrar la empresa y consultar el estado de la licencia. El uso diario (ventas, stock, empleados) funciona sin conexión; hay un margen de gracia de 7 días.

3. Licencias Free y Premium

Free

Incluye la gestión esencial: dashboard, registro de ventas y movimientos, y carga de empleados. Durante el trial se accede a todas las funciones.

Premium

Habilita el nombre de tu empresa en el menú y en los comprobantes, el teléfono y la dirección en el menú, y las funciones avanzadas. Elegí 30 días, 1 año o sin vencimiento.

Activación

Después de acreditado el pago por MercadoPago o transferencia, el proveedor activa Premium desde su consola. Para ver el cambio, abrí Configuración → Premium en la aplicación.

Ver medios de pago

Trial y vencimiento

El estado se calcula en el servidor de licencias. Si el equipo estuvo sin conexión, abrí la pestaña Premium para sincronizar la fecha real de vencimiento.

4. Uso diario

Ventas (POS)

Cargá productos, aplicá cantidades y cerrá la venta. Los lectores de código de barras USB funcionan como un teclado: escanean y presionan Enter.

Productos y stock

Alta de productos, categorías, elaborados, combos y recetas. Los movimientos de stock quedan registrados con fecha y usuario.

Compras y proveedores

Registrá compras, cargá el proveedor y controlá las cuentas. Los saldos se pueden saldar desde el listado de proveedores.

Empleados y roles

Creá usuarios con rol ADMIN o CAJERO. Los roles restringen el acceso a pantallas como Dashboard, Movimientos y Empleados.

5. Mantenimiento y soporte

Backups

Ejecutá backup.bat para generar una copia manual en la carpeta backups\. Se conservan los últimos 14 días y también hay backup automático diario si activaste el autoarranque.

Olvidé mi contraseña

Escribinos por WhatsApp. El proveedor genera un código de recuperación de 4 dígitos, válido por 30 minutos, que se usa en la pantalla de login.

Pedir código

Registrar otra empresa

Desde la configuración podés reiniciar el sistema. Se genera un respaldo automático primero y luego se borran los datos locales para crear otra cuenta.

Detener o iniciar

iniciar.bat levanta el sistema en segundo plano y detener.bat lo apaga. Si el puerto 3000 está ocupado, cambiá APP_PORT en config.env.

Preguntas frecuentes

¿El sistema funciona sin internet?

Sí para el uso diario. Necesitás conexión al registrar la empresa y para verificar la licencia; hay un margen de gracia de 7 días sin conexión.

¿Puedo usar más de una computadora?

Cada instalación es independiente. Para múltiples puestos, consultanos por WhatsApp y te indicamos la mejor opción según tu caso.

¿Dónde veo los días de prueba restantes?

En Configuración → Premium. Esa pestaña sincroniza con el servidor al abrirse.

¿Cómo sé si Premium ya está activo?

En Configuración → Premium aparece el estado y la fecha de vencimiento. Si no se actualiza, verificá la conexión y volvé a abrir la pestaña.

¿Necesitás ayuda?

Escribinos por WhatsApp para consultas de instalación, licencias, activación o recuperación de contraseña.
